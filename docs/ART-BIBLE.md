## Critical standard

**If the implementation can be described as "cards, gradients, borders, icons, and simple geometric illustrations," it has not yet reached the 103 Arcade visual standard.**

HTML/CSS/JS orchestrate gameplay, UI, interaction, state, animation, and accessibility.  
**Artwork** is responsible for the visual world.

## Do

- Consume real raster layers (WebP environments, PNG characters/props with transparency)
- Match dashboard franchise lighting, depth, and storybook cinematic children’s illustration
- Layer scenes: sky → mid → environment → foreground → characters → interactive → content → HUD
- Reuse canonical Owl / Bee / Turtle forever

## Do not

- CSS gradients, basic polygons, circles, emoji, or clip-art SVG as finished world art
- Cyberpunk corridors or neon as *world* identity (UI chrome may stay neon)
- New one-off mascots per screen
- Hotlinks or scrap downloads
