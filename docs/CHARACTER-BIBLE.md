# 103 Arcade — Character Bible

## Canonical reuse rule

**Never generate a new version of an established character when the character already exists.**

The Reading Owl, Spelling Bee, and Math Turtle are canonical. All games reuse approved assets and poses.

## Reading Owl

- Soft tan/brown owl, large eyes, blue vest/scarf
- Poses: idle, happy, thinking, flying, celebrating, gentle-error
- Assets: `worlds/reading/characters/reading-owl-*.png`
- Also used by SentenceQuest, RhymeTime, FlipMatch companions

## Spelling Bee

- Rounded yellow bee, dark stripes, cyan wings, friendly antennae
- Poses: idle, happy, thinking, flying, carrying-letter, celebrating, gentle-error
- Assets: `worlds/spelling/characters/spelling-bee-*.png`
- AbcBuzz **must** reuse these (not a different bee)

## Math Turtle

- Friendly green turtle, soft shell, optional backpack
- Poses: idle, happy, thinking, walking, carrying-number, celebrating, gentle-error
- Assets: `worlds/math/characters/math-turtle-*.png`
- PatternPop reuses these

## Expressions

| Pose | Use |
|---|---|
| idle | Default map / play idle bob |
| happy / celebrating | Correct answer, lesson complete |
| thinking | Hint / pause |
| gentle-error | Soft miss — never shame |
| flying / walking | Transitions |
